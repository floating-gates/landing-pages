## Check the Dashboard

You will see that an order appears:

![Order on the dashboard](../images/docs-images/interact-with-your-first-order-1.png)

## Inspect the order

From the order you can download the device, inspect it, and produce a price for it:

![Inspecting the order](../images/docs-images/interact-with-your-first-order-2.png)

## Set the price

Use the price input below and send the quote:

![Setting the price](../images/docs-images/interact-with-your-first-order-3.png)

In the meantime the user has been sent an email with your formal offer, and they can accept or refuse it:

![Customer accepting the offer](../images/docs-images/interact-with-your-first-order-4.png)

Once accepted:

![Order accepted](../images/docs-images/interact-with-your-first-order-5.png)

From now on you can start manufacturing the device. Later, you can send the invoices and declare the shipment. Once you have declared the order shipped, it is considered closed.

![Declaring shipment](../images/docs-images/interact-with-your-first-order-6.png)

Done, you have sold a propeller.
